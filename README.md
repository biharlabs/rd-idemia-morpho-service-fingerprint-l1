## 📦 Installation Guide

Once you receive your script file via Email or WhatsApp:

### Step 1: Install a Userscript Manager
Install one of the following browser extensions:
* **[Tampermonkey](https://www.tampermonkey.net/)** (Recommended for Chrome, Edge, Brave)
* **[Violentmonkey](https://violentmonkey.github.io/)**

### Step 2: Enable Local File Access (If opening file locally)
1. Open Chrome/Edge and go to `chrome://extensions`.
2. Find **Tampermonkey** and click **Details**.
3. Toggle **ON** the option: **"Allow access to file URLs"**.

### Step 3: Install the Script
* **Method 1 (Drag & Drop):** Drag the received `.user.js` file into your browser, and Tampermonkey will prompt you to install.
* **Method 2 (Manual Setup):** Open the Tampermonkey Dashboard, click the **`+` (Add Script)** tab, copy and paste the code from your received file, and press `Ctrl + S` to save.

### Step 4: Refresh & Test
Open your banking or CSC portal, refresh the page, and test device discovery and capture.
